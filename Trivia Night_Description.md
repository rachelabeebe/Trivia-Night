# Interactive Quiz App: Project Description

1. Project Title: Trivia Night

2. Objective  
The primary objective of Trivia Night is to create a fun, interactive, and responsive webpage that enables users to test their knowledge on a variety of subjects. The user will receive instant feedback on their result to each question and a final overall score. They will have the option to skip questions they do not wish to answer that will not be factored into the overall score. The project aims to offer a simple and intuitive experience.

3. Requirements  
** 3.1 Functional Requirements  
- Quiz Selection: allows users to decide which quizzes they would like to take  
- Question Display: users can see one question at a time and cannot go back to change their answer to previous questions  
- Answer Submission: enables users to select and submit their answers  
- Multimedia Integration: support images, video, or audio within questions or answers

** 3.2 Non-functional Requirements  
- Performance: All pages must load quickly.  
- Responsiveness: The application must be fully functional and interactive on all screen sizes.  
- Usability: The design should be easy to understand for the user.

4. User Stories  
- As a user, I want to see a broad scope of topics to choose from such as pop culture, science, history, and sports  
- As a user, I like whimsical colors, images, and animations  
- As a user, I would like the answers to the questions to be verifiable on other sources such as online encyclopedias  
- As a user, I would like to see the correct answer to the question if I got it wrong

5. Implement Details  
- HTML Structure: Create the basic layout for the quiz, including a container for questions and buttons  
- CSS: Styling  
- JavaScript: User interaction, provides immediate feedback, score calculation

6. Deliverables  
The successful completion of Trivia Night will result in the following:  
- A website that is deployed through GitHub Pages that meets all functional and non-functional requirements  
- Source Code: Clean, well-commented, and organized source code for the frontend
